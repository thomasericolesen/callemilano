# CalleMilano

CalleMilano is a family travel guide to Andalusia and Spain. Its recommendations are based on places saved in Google Maps and are organized to help families choose and plan outings.

## Place categories

- Restaurants
- Beaches
- Excursions
- Nature
- Cities
- Family activities

## Place content

Each published place should include a short description, a long description, recommended age groups, one-way driving time from Casa de la Familia in Urbanización Cerros del Águila, Las Lagunas de Mijas, tags, an SEO title, an SEO description, and alt text for each image. See [AGENTS.md](AGENTS.md) for the full content guidance.

## Project folders

- `docs/` — project and editorial documentation
- `data/` — structured place records and source data
- `images/` — images used by the guide
- `prompts/` — reusable prompts for research and content drafting
