## Disposition key

- **Recommended action:** `Research selected` / `Update existing record` / `Merge as duplicate` / `Clarify` / `Hold / reserve` / `Exclude for this batch`.
- **Proposed category / content type:** one exact approved category (`Restaurants`, `Beaches`, `Excursions`, `Nature`, `City`, `Family activities`) plus one template (`Attraction`, `Town`, `Beach`, `Restaurant`, `Nature/Hiking`); use uncertain when needed.
- **Launch priority:** provisional `0–100` score plus band (`75–100` first-pass research; `55–74` reserve/compare; `<55` defer unless distinctive). Add rationale in Known issues.
- **Evidence coverage / trust:** current supported applicable questions ÷ all applicable material guest questions; include unresolved-conflict count. Maps-only items normally score 0%.
- **Estimated editorial effort:** remaining active hours to a review-ready page; use a range and state major uncertainty. Do not confuse it with AI triage effort.
- **Missing information:** distinguish `Not yet researched`, `Searched, not found`, `Conflicting`, and `Not applicable (reason)`.
- **Known issues:** identity/duplicate concern, source conflict, season/closure, broad scope, or other review trigger. Record an owner/next step for material issues.
